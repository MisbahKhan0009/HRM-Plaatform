# Card

A card or panel on the current ground: `surface` fill, 1px `line` border, `bm-r-lg` corners, 20px padding, its children stacked 10px apart.

- **Provide:** `children`; optionally `as` to change the element (`"article"`, `"li"`).
- Typical content: a mono `label` in `text-3`, a title in the display face (600, about 17px, −1.5%), and copy in 14px `text-3`.
- On Ink the fill is Ink 2; on Paper it equals the ground, so the hairline border is what sets it apart.
- No drop shadows, no coloured side borders. Nothing rounder than `bm-r-lg`.
