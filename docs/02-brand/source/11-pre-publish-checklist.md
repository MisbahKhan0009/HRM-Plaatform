# Pre-publish checklist

Eleven checks before anything goes out.

- [ ] Logo is an approved version, unstretched, with clear space and above minimum size (`logo-min-lockup`, `logo-min-cube`).
- [ ] Background is Ink or Paper (`ground`), or a darkened photo with the white logo.
- [ ] The signature is there: the full-bleed dot grid and the red glow, both visible at the size the piece is seen (slides use the presentation scale).
- [ ] Red covers about 10% of the piece, with no more than one red emphasis word.
- [ ] No blue outside the logo, and no floating cubes or particles.
- [ ] Headlines in Inter Tight (or Arial bold), labels in mono caps.
- [ ] Every claim has a real number or a real example behind it.
- [ ] Name written as Big-Matrix Solutions / Big-Matrix; URL as big-matrix.com.
- [ ] No patient data or identifiable patients anywhere in the image.
- [ ] Exported at the size in the social table, as PNG, sRGB.
- [ ] Text is clear of the profile-picture overlap and at least `margin-graphic` (8%) from the edges.
