# Brand source: Big-Matrix Solutions design system

A snapshot of the company design system, taken 2026-10-22 from the owner's Claude design-system artifact (version `1792700369-0fba`). **The artifact is the source of truth.** Re-sync this folder when the brand changes; never edit these files by hand.

| File | What |
|---|---|
| `brand-book.md` | Brand book: voice, colour, typography, signature elements, layout |
| `tokens.json` | All design tokens (Ink/Paper themes) |
| `components/*.md`, `bundle.css`, `index.d.ts` | Reference component specs (marketing components) |
| `logos/` | Lockups (SVG masters + PNG) and cube mark |
| `09-social-media.md`, `11-pre-publish-checklist.md` | Marketing rules |

The HRM app adapts this brand into a product UI system in Stage 5/6 (`docs/02-brand/APP-UI-ADAPTATION.md`, to be written). Fonts are Inter, Inter Tight and JetBrains Mono, all free on Google Fonts (OFL).
