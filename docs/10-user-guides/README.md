# User guides

Written in Stage 12 (training and handover), once the screens exist, so the screenshots and steps match the real product. Planned guides:

| Guide | Audience | Covers |
|---|---|---|
| `EMPLOYEE-GUIDE.md` | All employees | Sign-in with passkey or email code, check-in/out, leave, transport claims, payslips, documents, profile changes, theme toggle |
| `MANAGER-GUIDE.md` | Managers | Approval inbox, team attendance and leave, reviewing corrections and claims |
| `HR-GUIDE.md` | HR admins | Employees and lifecycle, schedules, holidays, leave policies, documents, reports |
| `PAYROLL-GUIDE.md` | Payroll officer, Director | Salary structures, payroll run lifecycle, cash/cheque payments, payslips, reconciliation |
| `ADMIN-GUIDE.md` | System admin | Users, roles, settings, system health, backups (links to `docs/08-operations/`) |

Rules: written for non-technical readers, task-based ("How do I…"), one screenshot per step where it helps, English first and Bangla later (D-003).
